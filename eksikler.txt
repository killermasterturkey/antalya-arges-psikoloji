⚠️ EKSİK 3: GOOGLE ADS DÖNÜŞÜM TAKİBİ - KOD HAZIR, AKTİVASYON BEKLİYOR
--------------------------------------------------------------------------------

Mevcut Durum: KOD MEVCUT AMA YORUM SATIRINDA
Önem Derecesi: KRİTİK
Tahmini Aktivasyon Süresi: 15 dakika

AÇIKLAMA:
analytics.ts dosyasında Google Ads conversion kodları hazır ancak
yorum satırı içinde. Google Ads hesabından Conversion ID ve Label
alındıktan sonra aktive edilmeli.

MEVCUT KOD (src/utils/analytics.ts):
```typescript
// Google Ads Conversion (AW-XXXXXXXXX değeri Google Ads'den alınacak)
// if (typeof window !== 'undefined' && window.gtag) {
//   window.gtag('event', 'conversion', {
//     send_to: 'AW-XXXXXXXXX/YYYYYYYYYYYY',
//     value: 200,
//     currency: 'TRY',
//   });
// }
```

AKTİVASYON ADIMLARI:
1. Google Ads > Araçlar > Ölçüm > Dönüşümler
2. + Yeni dönüşüm oluştur
3. Dönüşüm ID ve Label değerlerini al
4. analytics.ts dosyasındaki yorum satırlarını kaldır
5. AW-XXXXXXXXX/YYYYYYYYYYYY değerlerini gerçek değerlerle değiştir

DÖNÜŞÜM TİPLERİ İÇİN ÖNERİLEN DEĞERLER:
- Telefon Tıklama: 200 TL
- WhatsApp Tıklama: 150 TL
- Form Gönderimi: 300 TL
